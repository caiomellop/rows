# Architecture decision records

One file per decision: `NNNN-short-title.md`, numbered in order. Keep each one short.

```
# NNNN. Title

Date: YYYY-MM-DD · Status: Accepted | Superseded by NNNN · Linear: CAI-XX

## Context
What problem or constraint forced a decision.

## Decision
What we chose, stated plainly.

## Consequences
What this makes easier, what it makes harder, what agents must now do or avoid.
```

A decision is recorded when it adds a vendor, SDK or service, sets a pattern other code must follow, or changes the repo structure. A superseded record is kept and marked, not deleted.
